Software Development

Software Development covers the interfaces, internal tools, and application code that make technical workflows accessible — configuration tools, monitoring views, and lightweight apps built to support data systems.

Overview

My software development work focuses on building interfaces and tools that sit on top of data pipelines and analytics systems. These are not standalone SaaS products — they are purpose-built applications that make technical workflows usable by people who should not need to touch a terminal.

The goal is software that is functional, maintainable, and scoped to solve a specific access or usability problem for a specific user.
