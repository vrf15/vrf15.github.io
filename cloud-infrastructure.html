Cloud & Infrastructure

Cloud & Infrastructure covers the AWS provisioning, networking, security, and deployment configuration underneath every pipeline and application in this portfolio.

Overview

My cloud work focuses on provisioning and configuring the AWS resources that my data pipelines and applications run on. Across projects, I set up compute, storage, database, and networking layers — and configure IAM roles, security groups, and access policies to keep things locked down.

The goal is infrastructure that is repeatable, scoped to least privilege, and documented well enough that I could tear it down and rebuild it from notes.

Featured Projects

WhetherX

EC2 compute, S3 storage, RDS PostgreSQL, VPC networking, and IAM configuration supporting the weather analytics pipeline.

SP500 Analytics

Cloud infrastructure for multi-API ingestion at scale, including rate-limit-aware compute provisioning and storage layer design.

SmartVault

Production-pattern infrastructure with dual-write storage (S3 + RDS), Docker/Celery/Redis orchestration on EC2, and environment-level secrets management.

AWS Services Used

EC2

Used as cloud compute for running pipeline services, Airflow workers, and development environments.

S3

Used as object storage for raw and semi-structured data before loading into relational layers.

RDS PostgreSQL

Used as the managed relational database for ingested data, transformed tables, and analytics-ready schemas.

VPC

Used to isolate project resources with subnet design separating public-facing and internal services.

IAM

Used to scope access policies and roles to least-privilege for each service and pipeline component.

Security Groups

Used as instance-level firewalls to restrict inbound/outbound traffic to only required ports and sources.
