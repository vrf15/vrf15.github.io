# vrf15.github.io

Static GitHub Pages skeleton for a Full-Stack BI Developer portfolio.

## Pages

- `index.html`
- `projects.html`
- `case-studies.html`
- `stack.html`
- `contact.html`
- `projects/template.html`

## Publishing

Create a GitHub repository named `vrf15.github.io`, push this folder to the `main` branch, and enable GitHub Pages from the repository settings if needed.
